# Knowledge folder

Drop extra `.md` or `.txt` files here: case study write-ups, a portfolio summary,
blog posts, talk notes. Every file in this folder is loaded into the bot's context
automatically (except this README).

Tips:
- One topic per file, e.g. `case-study-onboarding.md`, `design-principles.md`.
- Remove anything confidential or personal before adding it.
- Plain text is best. Paste content from PDFs or slides as plain text.
